## 🌟 Featured Projects

### 📁 AlphaDrive

A modern, lightweight, self-hosted cloud drive designed for Linux VPS servers.

AlphaDrive gives you a private file storage and sharing solution that you can run on infrastructure you control.

**Highlights:**

- ⚡ Single compiled Go binary
- 🗄️ Embedded SQLite database
- 📁 File and folder management
- 🔗 Public file sharing
- 🔐 Password-protected shares
- 🖼️ File previews
- 💾 Built-in backups
- 🩺 Diagnostics and health checks
- 🐧 Linux-friendly deployment
- 🚀 No Docker, Node.js, or external database required

👉 **[Explore AlphaDrive →](https://github.com/AlphaTechiess/alphadrive)**
